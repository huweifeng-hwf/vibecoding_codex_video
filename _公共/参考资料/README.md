## 证据与采用状态

- **原文已读**：已读取论文摘要、官方说明、README 或明确指出的源码文件。
- **条款已读**：已检查资源所列的许可说明；不代表任意下属素材、权重或用途已获准。
- **已实测**：必须附实际环境、输入、步骤和结果；供应商演示、README 测试数量与本项目实测分开。
- **采用方法**：吸收为本仓库工作约定，仍需要作品反馈验证。
- **优先试用／条件试用**：可以进入小样选型，尚未成为正式生产依赖。
- **仅参考／暂缓**：用于方法研究，或仍受许可、环境、维护和适配问题限制。

下载前按[素材采集 SOP](../教程/SOP/04_素材采集与复用.md)核对具体文件；接入工具前使用[接入卡](../模板/外部资源接入卡.md)。新条目保留资源编号、官方链接、依据、日期、用途和当前验证状态。
