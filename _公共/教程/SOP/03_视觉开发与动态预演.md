# 视觉开发与动态预演

状态：方法待作品验证。依据 [Runway References](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)、[Gen-4 Video 指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)、[Seedance 2.0 指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)与[Storyboarder](https://github.com/wonderunit/storyboarder)组织。

## 输入

当前剧本、分集目标、角色／场景／声音设定、已可用素材、目标画幅及实际工具能力。未确定供应商时先完成制作意图，不猜测工具已支持某种输入。

## 视觉开发

1. 用参考板说明构图、色彩、光线、材质和空间意图，记录哪些可用于正式制作、哪些仅用于研究。
2. 建立角色外观、服装与状态变体，关联文学角色编号；声音也保存明确版本。
3. 场景描述布局、出入口、视线、主要道具和常用机位。必要时用简单平面图、草图或 3D 预演。
4. 对参考资产做少量跨角度、景别和动作检查，记录已观察的漂移。确认后的版本进入项目资产索引。

## 分镜与预演

每个镜头说明它承担的剧情信息、表演动作、起止状态、构图与景别、机位运动、声音和剪接关系。编号和排序分开。

使用静帧和粗配音建立时间线，先检查观众能否理解动作和空间、信息揭示是否合适、对白是否有表演时间。记录实际预演时长与反馈，再调整分镜。

没有媒体或尚未观看时，结论限于分镜计划；不能宣称预演、表演或口型已经通过。

## 提示词按工具适配

| 制作意图 | 转为工具输入前确认 |
| --- | --- |
| 锁定角色与服装 | 支持的参考类型、数量、主体绑定和已选资产版本 |
| 控制动作与镜头 | 单镜头任务、起止状态、运动方式、可用时长与编辑能力 |
| 表演与对白 | 是否支持音频输入或音画联合生成、音色和时序控制 |
| 保持与排除的特征 | 工具是否支持对应约束字段，或需要改写为正向描述 |
| 局部返工 | 是否支持编辑、延长、重绘及可保留的输入状态 |

Runway Gen-4 视频指南明确不支持负向提示词，并建议简洁动作描述与逐项增加因素；这条规则只用于对应模型。Seedance 指南区分参考、编辑和延长任务，引用措辞也不同。不能把任一模型的参数或写法设为全仓库通用要求。

为实际工具填写[接入卡](../../模板/外部资源接入卡.md)，将提示词、模型标识、参考版本、输出和失败原因写入本剧生成记录。按已授权范围与预算生成；仅准备分镜或提示词时不发起计费任务。

## 验收

检查故事可理解性、表演、角色／道具／场景连续性、可编辑性，以及按实际结果计算的成本与耗时。代表性镜头通过本剧标准后再扩量，参见[小样 SOP](05_作品评审与小样验证.md)。
