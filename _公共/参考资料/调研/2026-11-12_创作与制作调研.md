# 小说与 AI 短剧创作准备调研

日期：2026-11-12。范围：小说质量、影视改编、视觉与声音制作、素材来源、开源工具和 agent skills。尚未开始具体作品，没有调用计费生成服务，也没有对成片质量或收益作实测结论。

## 结论与采用方式

建议以“创作决策、持续状态、分层评审、可编辑制作、小样验证”组织工作。先将方法写成 SOP 和仓库技能，再按第一部作品的形态选择模型、剪辑工具和素材。工具的自动化范围与文学或影视质量分别评价。

## 对高质量小说的具体约定

1. **先明确读者体验。** 立项记录受众、题材承诺、人物矛盾和作品独特之处；结构与篇幅服从这些目标。
2. **维护会变化的故事事实。** 人物知道什么、想得到什么、关系如何变化，与静态人物小传分开记录。
3. **把章节落实到场景。** 场景至少有视角、目标、阻力、选择和结束变化；过渡或抒情场景也应能说明其作用。
4. **保护文体与作者取舍。** 记录视角、叙述距离、语言节奏和原创文体样本；探索方案不自动进入已确认设定。
5. **分层修订。** 先处理主线、因果、人物，再处理场景与对白，最后处理语句和校对；已知会删改的段落先不精修。
6. **读者反馈单独保存。** AI 的模拟读者反应属于假设，真实试读的理解、期待、困惑和流失点另记。

工作步骤见[小说 SOP](../../教程/SOP/01_小说开发与分层修订.md)，对应技能为 `develop-fiction`。

## 对高质量短剧的具体约定

- 改编先判断要保留的戏剧功能，再设计可见、可听的场面；重要新增或合并带出处和理由。
- 分集有真实推进、人物行动与结果；开头和结尾设计通过样片反馈检验，不预设统一的秒数公式。
- 分镜同时说明叙事职责、表演、构图、空间和剪接，不能只写美术形容词。
- 参考图、服装变体、关键道具、视线和人物知情顺序都进入连续性检查。
- 声音先参与节奏设计。对白能朗读、表演，音乐与音效有作用，正式镜头按实际时长调整。
- 试制覆盖代表性难点，例如对话、转身、道具操作与跨镜连续性；先证明能制作，再扩量。

步骤见[改编 SOP](../../教程/SOP/02_改编与对白审读.md)、[视觉与预演 SOP](../../教程/SOP/03_视觉开发与动态预演.md)和[评审 SOP](../../教程/SOP/05_作品评审与小样验证.md)。

## 资源和工具的选择

| 资源组 | 本轮建议 | 原因与限制 |
| --- | --- | --- |
| Poly Haven、ambientCG、Kenney 指定 CC0 资源 | 优先进入素材候选 | 适合材质、场景物件与预演；具体美术风格需匹配 |
| Freesound、Wikimedia Commons | 逐文件筛选 | 每项许可可能不同，保留作者、条款和证据 |
| Pexels、Pixabay、Mixkit | 条件使用 | 属于平台内容许可或分类型许可，不能统称 CC0 |
| Noto CJK | 优先试用字幕字体 | 已读 Sans 的 OFL 1.1；记录实际字体与随包许可 |
| FFmpeg／ffprobe、Fountain、OpenTimelineIO | 优先验证基础交付能力 | 检查与交换资料；不能替代剪辑、审美和工具适配 |
| ComfyUI 与官方工作流模板 | 条件试用 | 可保存工作流；节点、模型、硬件和输出仍需分别核验 |
| Wan2.2、LTX-Video、CosyVoice、GPT-SoVITS、faster-whisper | 按需求小样选型 | 未下载权重或做本机推理；不直接指定为生产栈 |
| F5-TTS 公开预训练模型 | 暂缓默认商业用途 | 仓库代码 MIT，README 将预训练模型标为 CC-BY-NC |
| manju-tool | 优先研究 CLI 接口并条件试用 | MIT；作者明确列出 API 差异、依赖未锁定及未实测计费 API 等限制 |
| huobao-drama、waoowaoo、Remotion | 先研究架构与许可 | 分别有 NC、Elastic License 2.0、专用商业许可等条件 |

本轮验证仓库资料、技能结构、链接、模板与任务走查。没有完成真实小说试读、媒体生成、配音、剪辑或发布验证，不能将这些环节标为已验证。
