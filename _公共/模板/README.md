# 模板使用说明

模板只定义结构与填写要求，不包含作品、章节、角色或实际发布结果。按当前阶段填写，尚未使用的文件保持模板状态。

## 创建作品

用户明确开始立项后，在仓库根目录执行；将名称替换为实际作品名，目标目录必须不存在：

```bash
project_name='替换为已确认的短剧名称'
if [ -e "$project_name" ]; then
  echo '目标已存在，停止复制'
else
  cp -R '_公共/模板/短剧项目' "$project_name"
fi
```

复制后：

1. 填写项目 README、项目立项、权利与来源、创作进度；开始填写的文件改为草稿。
2. 确定小说先行或分批改编、样片目标、初始制作范围及渠道待核验项。
3. 在根 README 的作品索引登记项目入口和当前阶段。
4. 按创作流程逐步填充。不要把模板占位符当作已经确认的设定。

## 创建章节和剧集

- 复制项目内的 `02_小说正文/章节模板.md` 为 `第001章_章节名.md`，填写章节编号与状态。
- 复制 `05_分集制作/分集模板/` 为同级的 `第001集/`，填写剧集编号和引用版本。
- 母版不计入章节或集数；增加内容时检查已用编号，避免覆盖现有文件。
- 项目模板的 Markdown 链接只指向项目内部，复制到仓库根目录后仍可使用。
