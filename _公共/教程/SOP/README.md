## 使用约定

按当前任务读取需要的 SOP，不要求每轮重复完整流程。用户已经确认的决策与授权持续有效；探索、草稿、确认和实际结果分别标记。

本目录保存可复用方法。本剧的范围、质量目标、工具、参数、费用、失败及评审结果写入作品目录；首次实作后回填有效经验和不适用条件。
