# 内容与版本管理

## 正式来源

| 内容 | 正式来源 | 其他文件的使用方式 |
| --- | --- | --- |
| 小说文本 | 对应章节正文 | 改编稿引用章节编号与版本 |
| 文学人物与世界规则 | 小说框架 | 制作设定引用角色编号；影视化差异写入改编方案 |
| 短剧情节结构 | 全剧结构、分集大纲 | 分集剧本细化；重大偏离同步策划 |
| 单集对白／旁白 | 每集 `剧本.md` | 分镜引用对白编号，台词表从剧本导出 |
| 外观、场景、声音 | 制作设定 | 提示词与镜头引用对应版本 |
| 资产位置与来源 | `04_制作设定/资产索引.csv` | 分集素材清单引用资产编号＋版本 |
| 镜头选用 | 每集 `素材清单.csv` | 候选／选用／弃用分开；导出依据选用项 |
| 发布结果 | 渠道对应的平台记录 | 项目入口只摘要，不伪造或推测结果 |

小说与短剧分别确认正式稿。改编允许合并、删减、重排与新增；涉及人物动机、世界规则或结局的重要变化，应写明原文依据、改编理由和影响。

## 版本

- Git 保存普通文本修订；正式文本持续维护原文件，不增加 `最终版2`、`新版最终` 等副本。
- 重要确认写入进度或决策记录，记录路径、提交标识、确认范围及日期。确认提交提交后回填；尚未提交时明确标记待回填。
- 资产使用同一资产编号配合独立版本；变更外观、配音或文件内容时增加版本，不覆盖已被成片引用的文件。
- 生成记录保存剧本、分镜和参考资产版本。模型未知时写未知，不用当前模型名称替代历史记录。
- 历史导出和已发布成片放在外部存储，以交付记录定位；不在 Git 中堆积视频版本。

## 已确认内容的修改

修改前说明影响；在当前授权范围内执行。未经授权的重大走向变化作为提案保存。修改后受影响的下游资料转为待复核，不能继续沿用旧的“已确认”。

对白变更至少复核配音、口型、字幕、镜头时长和剪辑；角色外观变更至少复核参考图及使用该版本的镜头。

## 事实与反馈

- 推测、创作提案、已确认设定和实际操作结果明确区分。
- 平台规则记录来源、日期和适用范围。缺乏证据时保留待核验。
- 数据复盘记录统计时间与指标口径。制作成本、投放费用和平台收益分别记录，不将空值当作零。
