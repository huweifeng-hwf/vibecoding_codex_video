# AI 镜头制作规划

读取根 AGENTS.md、项目目标、当前剧本与制作设定，按需读取[视觉与预演 SOP](../../../_公共/教程/SOP/03_视觉开发与动态预演.md)。源文本、制作意图和工具输入分别管理。

## 规划

1. 确认目标形态、画幅、节奏、表演需求与制作范围；已有选择继续沿用。
2. 将角色、服装／状态变体、场景布局、道具与声音关联到稳定编号和资产版本；参考来源与可用范围按素材规范登记。
3. 每镜说明叙事职责、可见动作、起止状态、景别、构图、空间／视线、镜头运动、对白引用和剪接关系。
4. 先用静帧和粗配音规划动态预演，按实际朗读、动作和观看反馈调整时长；未制作时明确标为计划。

## 工具适配

使用[接入卡](../../../_公共/模板/外部资源接入卡.md)记录实际模型／工具版本、参考类型、主体绑定、音频、时长、编辑与约束能力。未选工具时保留制作意图，不编造参数。

按官方文档分别适配提示词：例如某模型不支持负向提示词时转为其支持的正向表达。不要把供应商的一条经验变成所有模型的限制；能力会随版本变化，采用时核验。

计划比较代表性难点而非仅测试最容易的空镜。记录固定输入、变化因素、预算、成功／失败与可用结果的统计口径。

## 交付与观察边界

交付本轮需要的设定、分镜、提示词或预演／小样计划，更新引用和进度。用户已授权的实际制作按范围执行，结果进入生成记录、资产索引和成本记录；只要求准备时不发起生成任务。

未实际观看或聆听的媒体不判断表演、口型、连续性与混音已通过。技术参数与艺术判断分开；返工只更新受影响镜头，保留旧成片的版本追溯。
