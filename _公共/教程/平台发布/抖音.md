# 抖音发布核验清单

状态：待核验；编写日期：2026-11-12；最后实际验证日期：未验证。

本文件还不是已验证的后台操作教程。账号视频发布、短剧相关发行路径、合作发行分别核验，不能据其中一种能力推断另一种已获准。

## 输入与前置条件

作品形态、拟使用的账号或主体、发行路径、权利清单、计划交付范围。

## 核验步骤

| 项目 | 需要取得的依据 | 当前结果 |
| --- | --- | --- |
| 作品分类与适用入口 | 当前官方规则与账号实际后台 | 待核验 |
| 主体、权限及相关审核要求 | 适用于该作品及发行路径的官方说明 | 待核验 |
| AI 生成／合成内容声明与标识 | 当前平台说明及适用要求 | 待核验 |
| 版权、审核、交付材料 | 对应入口的材料清单与格式 | 待核验 |
| 视频、字幕、封面与剧集组织 | 当前后台规格和实际验证 | 待核验 |
| 接口与数据权限 | 对应应用、账号权限及官方接口文档 | 待核验 |
| 收益、合作限制、撤回与下架 | 实际规则／合同和操作入口 | 待核验 |

## 产出与验收

按来源、核验日期、作品类别、账号条件和路径记录结果；在获准范围内完成交付测试，保存实际上传、审核和发布回执。不能只凭上传响应记为上线。

## 来源与后续补充

[抖音开放平台](https://open.douyin.com/)仅作为官方技术资料入口，不证明当前账号具备任何发布权限。进一步取得适用的具体规则页面后，登记到[来源索引](../../参考资料/来源索引.md)，再补充可执行操作步骤、费用和限制。
