## 维护约定

- 新教程使用[教程模板](../模板/教程模板.md)，注明适用范围、前置条件、步骤、产出、验收、问题及来源。
- 纯方法不虚构工具版本或费用；工具操作注明实际工具版本、模型标识及验证日期。
- 平台规则以官方资料和实际可访问后台核验，记录适用主体、作品分类与发行路径。
- 访问官网入口不等于验证规则。只有完成对应步骤并保留结果，才将状态改为已验证。
- 索引与正文状态保持同步；链接实作记录时避免暴露私人凭证。
