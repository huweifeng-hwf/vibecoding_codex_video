# 素材与权利管理

## 存储与追溯

- Git 保存文本、CSV 和少量便于审阅的参考图。大视频、音频、候选结果、缓存和剪辑临时文件放入 `_本地素材/`、`_缓存/` 或外部存储。
- `_本地素材/` 默认不提交；跨机器交接前确保选用素材已同步到双方可访问的持久位置，仅有本机绝对路径不算交付完成。
- `.gitignore` 默认忽略视听文件和 `导出/` 中的衍生物，保留导出说明。需要 Git LFS 或纳入特殊格式时，先明确团队存储方案再调整。
- 资产索引记录资产编号、版本、类别、关联对象、文件位置、来源、授权依据和状态；重要交付文件补充 SHA-256。
- 每集素材清单引用资产编号与版本，记录用途、镜头和选用状态；不能只保留一个无法解释来源的成片。
- 生成记录包括日期、工具／模型标识、参考资产及版本、提示词、关键参数、结果、费用和返工原因。供应商不暴露的字段明确写未知。
- 采集流程见[素材 SOP](../教程/SOP/04_素材采集与复用.md)，候选入口见[素材来源](../参考资料/素材来源与使用边界.md)。按具体文件记录证据；代码、权重、素材、服务条款与用途分别核验。

## 权利与来源

在作品 `00_项目管理/权利与来源.md` 记录：

1. 小说原创或授权来源，以及影视改编、传播、商业使用的授权范围和限制。
2. 图片、视频、音乐、字体、声音和其他外部素材的来源、许可版本、适用用途及核验依据。
3. 真人肖像或克隆声音等使用所需的授权情况；未完成的事项标记待核验。
4. 合作发行的地域、期限、独家限制和交付责任，按实际合同记录。

权利结论必须有依据；“AI 生成”不是授权证明。凭证原件、合同个人信息和账号资料保存在 `_本地凭证/` 或受控位置，仓库保留编号与必要摘要，不提交密钥、访问令牌或带签名的临时 URL。

本规范是项目资料管理要求。具体平台、作品类别及发行路径所需的审核和资质，按[平台教程索引](../教程/README.md)核验后记录。

## 交付检查

- 成片与封面、字幕、简介、剧集顺序匹配。
- 剧本、分镜、选用素材和最终文件版本可追溯。
- 用到的外部文件能访问，校验值与交付文件一致。
- 来源与授权待办、AI 声明及平台要求有实际核验记录。
- 上传、审核和发布的真实回执分别归档。
