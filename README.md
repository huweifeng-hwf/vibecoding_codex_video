# 小说与 AI 短剧创作资料库

按作品保存从故事构思、小说创作、短剧改编、AI 制作到发布复盘的资料，让创作过程可以持续修改、交接和复用。

## 三个基本约定

1. 每部短剧在仓库根目录拥有一个以作品名称命名的文件夹。
2. 通用规范、模板和教程集中维护在 `_公共/`，作品目录记录本剧的具体选择与实践。
3. 小说正文与短剧改编分别维护正式稿，通过改编方案和对应表记录关联及差异。

## 从这里开始

- 阅读[创作流程](_公共/规范/创作流程.md)，了解每个阶段的交付物。
- 按[目录与命名](_公共/规范/目录与命名.md)归档资料。
- 使用[模板说明](_公共/模板/README.md)创建项目；[短剧项目模板](_公共/模板/短剧项目/README.md)可完整复制。
- 通过[教程索引](_公共/教程/README.md)查找方法和待验证事项。
- AI 协作遵守 [AGENTS.md](AGENTS.md)。

## 维护原则

- Markdown 保存叙事和说明，CSV 保存分镜、资产、成本等结构化清单。
- 大体积素材与导出文件按[素材与权利管理](_公共/规范/素材与权利管理.md)存储，通过清单关联。
- 普通修订由 Git 追溯，重要确认记录提交；不复制出“最终版2”等平行文件。
- 平台准入、审核、AI 标识、收益和接口必须按实际路径核验。当前平台教程是核验清单，不表示已获得发布资格。
- 当前提供资料规范与模板，尚未接入生成或发布服务；具体作品在立项后创建。
