# 目录与命名

## 作品与公共资料

根目录按短剧名称建文件夹；共享资料位于 `_公共/`。作品改名属于目录迁移，需要同步根索引、内部引用和已有交付记录；发布时使用的旧名称仍保留在发布记录中。

`.agents/skills/` 保存仓库级技能定义，属于协作工具资料，不计入作品。公共 SOP 位于 `_公共/教程/SOP/`，外部来源和采用状态位于 `_公共/参考资料/`；作品中的具体结果仍由项目目录维护。

作品入口是 `README.md`。各层职责如下：

| 目录 | 保存内容 | 与其他层的边界 |
| --- | --- | --- |
| `00_项目管理` | 立项、进度、决策、权利与来源 | 记录目标和状态，不重复故事正文 |
| `01_小说框架` | 概念、世界观、人物、大纲、章节、时间线、伏笔 | 文学层面的设定 |
| `02_小说正文` | 按章节保存的小说 | 小说正式文本及其修订 |
| `03_短剧策划` | 改编方案、全剧结构、分集大纲、对应表 | 全剧层面；详细单集剧本放在分集制作 |
| `04_制作设定` | 美术风格、角色外观、场景、道具、声音、资产索引 | 制作层面的稳定设定，引用文学角色编号 |
| `05_分集制作` | 每集剧本、分镜、提示词、素材清单、审片记录 | 每集一个目录，资料随集归档 |
| `06_发布与复盘` | 交付物料、平台记录、成本、反馈 | 区分计划与真实结果 |

## 文件格式

- UTF-8 文本；Markdown 用于叙事和说明，CSV 用于清单和表格。
- CSV 保留第一行字段名；使用半角逗号，包含逗号、双引号或换行的值按 CSV 规则引用。
- 可选项可以留空；未知成本和未核验结果留空或标注待核验，不能写成 0 或成功。
- 文件名使用中文描述，避免空格及 `<>:"/\\|?*` 等不便跨系统使用的字符。
- 章节使用 `第001章_章节名.md`；剧集目录使用 `第001集/`。作品规模超过 999 时统一扩位并更新规则。
- `章节模板.md`、`分集模板/` 是母版名，复制后再按正式编号命名。

## 编号与引用

| 对象 | 编号示意 | 作用域 |
| --- | --- | --- |
| 文学人物／制作角色 | `CHAR001` | 同一作品共用 |
| 场景 | `LOC001` | 同一作品共用 |
| 道具 | `PROP001` | 同一作品共用 |
| 资产 | `ASSET001` | 同一作品共用，版本单独记录 |
| 小说章节 | `CH001` | 同一作品 |
| 剧集 | `EP001` | 同一作品 |
| 镜头 | `EP001-SH001` | 所属剧集 |
| 对白／旁白 | `EP001-D001` | 所属剧集 |
| 生成任务 | `GEN001` | 同一作品 |

编号只是格式示意，不代表已创建对象。编号一经被引用便保持稳定；镜头、章节的展示顺序与编号分开。删除内容标注停用，不将已使用编号分配给其他内容。

正文使用 Markdown 锚点或文件路径引用；CSV 多值字段用分号分隔。角色、镜头、对白、素材通过编号关联，不只靠文件名猜测。

## 路径

- Markdown 内部链接相对于当前文档；作品模板尽量只链接自身内部文件，复制到根目录后仍可用。
- 清单中的文件路径默认相对于作品根目录；外部存储填写可定位 URI，不提交带临时签名或访问密钥的链接。
- 分集素材清单通过资产编号与版本引用资产索引，不另建一套文件位置事实。
- 教程、模板和参考资料的入口由各自索引维护。新增作品时更新根目录作品表。

参见[创作流程](创作流程.md)、[内容与版本管理](内容与版本管理.md)和[素材与权利管理](素材与权利管理.md)。
